# 轻松管理和最多5倍加速下载！

Online Download Manager — 加速、整理并掌控每一次下载

Online Download Manager 将浏览器原本简陋的下载栏，升级为一个快速、可靠、井井有条的下载中心。它完全基于 Manifest V3 全新打造，会把每个文件拆分成多条并行连接同时抓取，下载速度最高可提升至 5×，并配备简洁清爽的管理面板，让你在一个地方轻松暂停、续传、搜索、排序和管理所有下载任务。

## 亮点一览

### 多线程加速下载
Online Download Manager 不再用单一连接慢慢拉取文件，而是同时开启多个字节区段并行下载。对于 ISO 镜像、压缩包、安装程序、视频和数据集等大文件来说，这意味着等待时间大幅缩短。你可以自由设定使用的线程数量（1–5），实时的多段进度条会逐一显示每条连接的下载进度。

### 真正的下载管理器，而不只是一个文件清单
全新设计的管理器是一个功能完整的工作台。侧边栏可按状态筛选下载任务——下载中、已暂停、排队中、已完成和失败——每个状态都带有实时数量统计。即时搜索支持按文件名、主机或网址匹配。可按最新、名称或大小排序。每一行都清晰呈现精确进度、当前速度、已传输大小以及剩余时间的准确预估。

### 暂停、续传与恢复
随时停下一个下载，稍后再继续。中断的传输无需重头开始，可直接续传；进行中的任务也会被全程记录，即使关闭标签页或重启浏览器，也不会丢失已有进度。每个下载都支持一键操作：暂停、续传、重试、打开文件、在文件夹中显示、复制链接、打开来源页面，或从磁盘中删除。

### 右键即可加速
在右键菜单中添加“使用加速器下载”选项。无论是链接、图片、视频还是音频文件，右键点击即可直接发送到加速器——无需复制粘贴。

### 自动加速一切（可选）
开启自动捕获后，扩展会拦截你在浏览器任意位置发起的下载，并自动转入加速器处理。如果某个服务器无法加速，它会干净利落地回退为普通浏览器下载，绝不产生重复文件。

### 内置调度器与队列
一次要下载十几个文件？设置一个最大并发下载数，其余任务便会乖乖排队等候，并在有空位时自动开始。需要让某个任务插队？点击“立即开始”即可马上运行。即便重启浏览器，你的队列也依然保留。

### 带宽限制
限制总下载速度，避免大文件传输拖垮你的视频通话或游戏。以 KB/s 为单位设定上限，加速器便会在所有活动下载之间合理分配速度；设为关闭，则随时享受满速下载。

### 校验你下载的内容
粘贴可选的 SHA-256 校验值，扩展会在保存前对完成的文件进行校验，让你确信安装程序或压缩包与发布方提供的内容完全一致——若文件无法通过校验，它也会明确告知你。

### 批量添加与拖放
一次粘贴多个链接——用空格、逗号或换行分隔——即可一键加入队列；或者直接把任意页面上的链接拖到管理器，放进网址输入框即可。

### 让你随时掌握进度的通知
下载完成时会收到桌面通知，下载失败时还可开启额外提醒——这样你尽可放心地启动大文件下载，然后安心去忙别的事。

### 打造你的专属体验
在浅色、深色和跟随系统主题之间切换，选择舒适或紧凑的行间距，挑选喜欢的强调色。还可设置默认线程数、连接超时、重试次数、保存方式（自动保存或每次询问保存位置）等等。每一项设置都会在你修改的瞬间立即保存。

### 私密且值得信赖
Online Download Manager 完全在你的浏览器中运行。它不会在安装时弹出营销页面，不会用卸载问卷打扰你，也不会把你的下载内容发送到任何地方。你的文件直接从来源抓取到你的电脑。只有在你选择允许登录后下载时，才会发送你的 Cookie，你也可以将其关闭以获得更严格的隐私保护。

### 支持你的母语
界面和通知提供 40 多种语言，无论你身在何处，这款管理器都让你倍感亲切。

### 为现代 Chrome 而生
作为一款完全符合 Manifest V3 的扩展，Online Download Manager 快速、安全、面向未来。它采用高效的后台 Service Worker 和专属下载引擎，即使在大型多线程传输期间，也能保持极低的内存和 CPU 占用。

### 几秒钟即可上手
安装扩展，点击工具栏图标打开管理器，粘贴一个链接，选择线程数，再点击“添加”。就这么简单——每一次都享受更快、更省心、更有条理的下载体验。

> **注意：** Online Download Manager 加速的是来自支持区段请求的服务器的直接文件下载。它不是流媒体或 YouTube 下载工具。
